# منصة مواثيق | Mawatheq Platform

منصة قانونية احترافية (موقع + لوحة تحكم) بنفس روح قاضي برو، بهوية مواثيق البصرية.
جاهزة للرفع مباشرة على استضافة cPanel (PHP + MySQL).

## المحتويات
- `/` — الموقع العام (الصفحة الرئيسية، الأسعار، مركز المعرفة، التواصل...)
- `/admin` — لوحة تحكم الإدارة
- `/api` — نقاط اتصال AJAX (المحادثة الذكية، رفع المستندات)
- `/database/schema.sql` — قاعدة البيانات كاملة (جداول + بيانات أولية)
- `/config/config.php` — إعدادات الاتصال بقاعدة البيانات ومفاتيح الذكاء الاصطناعي

## خطوات الرفع على cPanel

### 1) إنشاء قاعدة البيانات
1. من cPanel افتح **MySQL Databases**
2. أنشئ قاعدة بيانات، مثال: `youruser_mawatheq`
3. أنشئ مستخدم قاعدة بيانات وكلمة مرور قوية
4. اربط المستخدم بالقاعدة وامنحه **All Privileges**
5. افتح **phpMyAdmin** → اختر القاعدة → تبويب **Import** → ارفع ملف `database/schema.sql`

> **إذا كنت تحدّث نسخة موجودة:** لا تستورد `schema.sql`. شغّل كل ملفات `upgrade_v*.sql` التي تتجاوز إصدار قاعدة بياناتك، تصاعدياً ومن دون تخطي أي إصدار. النسخة الحالية تصل إلى v37. إذا لم تعرف إصدار القاعدة، راجع دليل التحديث وخذ نسخة احتياطية قبل تشغيل الترقيات.

### 2) رفع الملفات
1. افتح **File Manager** أو استخدم FTP
2. ارفع كل محتويات هذا المجلد داخل `public_html` (أو داخل مجلد الدومين الفرعي إن وُجد)
3. تأكد أن الملفات في جذر الدومين مباشرة (يعني `index.php` يكون داخل `public_html` مباشرة، وليس داخل مجلد فرعي باسم المشروع)

### 3) إعداد أسرار الاستضافة
أنشئ `config/secrets.php` على الخادم من `config/secrets.example.php`، ثم أدخل بيانات قاعدة البيانات والبريد المرسل من cPanel. هذا الملف مستثنى من Git وممنوع الوصول إليه عبر الويب؛ لا ترسله أو ترفعه إلى مستودع عام. إن كانت بيانات اتصال قاعدة البيانات قد نُشرت سابقاً، غيّر كلمة مرور مستخدم قاعدة البيانات من cPanel قبل النشر.

### 4) الصلاحيات
تأكد أن مجلد `uploads/documents` قابل للكتابة (صلاحية 755 أو 775 حسب الاستضافة).

### 5) الدخول لأول مرة
- **الموقع العام:** `https://your-domain.com/`
- **لوحة التحكم:** `https://your-domain.com/admin/login.php`
  - عند تثبيت قاعدة جديدة، ضع مفتاحاً عشوائياً لا يقل عن 32 حرفاً في `ADMIN_SETUP_KEY` داخل `config/secrets.php`، ثم افتح `/admin/setup.php` وأنشئ المدير بكلمة مرور قوية، واحذف الصفحة من الخادم فوراً.
  - عند تحديث قاعدة قائمة، سجّل الدخول بحساب المدير الحالي؛ لا تستورد `schema.sql` ولا تشغّل إعداد المدير الأول.
- **دخول المحامين:** `https://your-domain.com/lawyer-login.php`
  - حسابات المحامين تُنشأ من لوحة التحكم (Admin → المحامون)، ثم يدخل كل محامٍ بحسابه الخاص لإدارة قضاياه واستشاراته.

## ربط الذكاء الاصطناعي الحقيقي
لم يعد هذا يحتاج تعديل أي ملف. من لوحة التحكم → **الإعدادات** → قسم "ربط مزوّد الذكاء الاصطناعي":
1. اختر المزوّد (Anthropic أو OpenAI)
2. الصق مفتاح API
3. احفظ — يعمل المساعد الذكي فوراً بردود حقيقية

بدون مفتاح، يستمر المساعد بالعمل بردود مبنية على مكتبة الأنظمة المحلية (بديل مؤقت آمن) حتى لا يتعطل الموقع أبداً. يتطلب هذا أن يكون امتداد PHP `curl` مفعّلاً على الاستضافة (مفعّل افتراضياً في كل استضافات cPanel تقريباً).

## المميزات المضافة في هذا الإصدار
- **تحليل عقد تفصيلي:** اختر نوع المستند «تحليل عقد» للحصول على استخراج منظم للبنود والالتزامات وشروط الدفع والإنهاء والتجديد والاختصاص والمسؤولية والتعويض ومؤشرات البنود الناقصة/غير المعتادة. النتائج آلية أولية وتحتاج مراجعة محامٍ، وتعتمد على وضوح النص ودعم مزوّد AI للملف.
- **مراجعة مسودات المكتب:** يمكن لمسودات مكاتب المحاماة المرور بمراجع محامٍ ثم شريك/مالك، مع سجل للقرارات والملاحظات ورقم نسخة. طلب التعديلات يعيد المسودة لمنشئها، ويُقيد تنزيل المسودات بعد بدء المسار حتى اعتماد المكتب.
- **مقارنة العقود:** يقارن حساب العميل نتائج التحليل المنظمة لعقدين مكتملَي التحليل، بعد الموافقة على الإرسال، ويحفظ النتيجة في حسابه. المقارنة لا تنشئ redline ولا تستبدل مراجعة النص الأصلي.
- **تسجيل مزدوج واضح:** صفحة `/register.php` فيها تبويبان — "أنا عميل" و"أنا محامٍ". تسجيل المحامي الذاتي ينشئ حساباً بحالة "بانتظار المراجعة" حتى يعتمده الأدمن من لوحة التحكم (المحامون).
- **بوابة محامٍ كاملة (`/lawyer/`)**: تسجيل دخول مستقل، إدارة القضايا (إنشاء، تحديث الحالة واحتمالية الفوز، جدول زمني)، إدارة الاستشارات، ملف شخصي.
- **CRM كامل للعملاء:** من لوحة التحكم → العملاء → "فتح الملف" لعرض كل استشارات/مستندات/قضايا العميل في مكان واحد، مع إمكانية إضافة ملاحظات داخلية لا يراها العميل.
- **استشارات صوت/فيديو حقيقية تعمل فوراً:** عند تأكيد استشارة نوعها صوت أو فيديو، يظهر للعميل والمحامي زر "دخول/Join" يفتح غرفة مكالمة مباشرة ومشفّرة (عبر Jitsi Meet) بدون أي إعداد إضافي أو تثبيت برامج.
- **استشارات نصية حقيقية:** استشارة من نوع "نص" تفتح محادثة فعلية بين العميل والمحامي (محفوظة بقاعدة البيانات، تحدّث تلقائياً).
- **قائمة جانبية قابلة للتمرير** في لوحات التحكم الثلاث (أدمن/محامي/عميل) عند إضافة عناصر أكثر من ارتفاع الشاشة.

## المرحلة التالية: ربط تطبيق الجوال (Flutter)
تطبيق مواثيق الحالي (Flutter) يستخدم بيانات وهمية (Mock). الخطوة القادمة:
1. بناء طبقة REST API إضافية فوق نفس قاعدة البيانات هذه (نفس الجداول)
2. استبدال طبقة الـ Mock داخل التطبيق (`lib/services` أو ما يعادلها) بنداءات فعلية لهذا الـ API
3. استخدام نفس نظام تسجيل الدخول (جدول `users`) بحيث يسجّل العميل دخوله من الموقع أو التطبيق بنفس الحساب

## ملاحظات أمنية مهمة
- غيّر كلمة مرور المدير الافتراضية فوراً
- لا تشارك محتوى `config/config.php` علناً (يحتوي بيانات قاعدة البيانات)
- فعّل شهادة SSL (HTTPS) من cPanel قبل الإطلاق الفعلي
