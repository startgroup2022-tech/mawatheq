# Banner photo attribution

The four built-in home-slider photos are bundled app assets. They are the default
slides the carousel shows when the operator has published no banner in
**Admin → Banners** (`home_banners` ships empty, so that is the normal fresh-install
state).

Two of the four are **CC BY 2.0**, which requires attribution wherever the work is
redistributed. The credit below satisfies that condition. Keep this file with the
images: removing it removes the licence to use them.

Each file was cropped to 1080×607 and re-encoded as JPEG; the cropping and the
re-encode are the only modifications. EXIF was dropped in the process, which is why
this table, not the files, is the record of provenance.

## Replacing them

A firm or operator who wants their own imagery should publish it through
**Admin → Banners** rather than editing these assets. An operator banner takes
precedence over every built-in slide, and `uploads/banners/` is the web-served
directory for those uploads. If you do swap a built-in asset, update this table —
the licence travels with the picture, not with the filename.
